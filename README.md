# Blisse Code

Blisse Code is a house for design and AI experiments. Some of them grow into products. The ones that grow get their own names.

The silent e in Blisse is there on purpose. It says nothing here is final.

Chiranjeet Banerjee runs it from Kuala Lumpur.

## About Chiranjeet

### I am

- An experience design manager, based in Kuala Lumpur.
- A designer who wandered into the terminal and never left.
- The photographer behind [Broekn Camera](https://broekncamera.com): editorial portraits and AI imagery.
- A writer on [Substack](https://blissecode.substack.com), mostly about design and the real cost of AI work.

### I do

- Mental models and information architecture first. Screens come last.
- Research before opinions. RICE, Kano or MoSCoW when the list gets long.
- Design choices tied to a business question someone can measure.
- AI workflows for designers, with checks a person can trust.

### How I work

I have no engineering background. So I direct AI agents the way I would run a design team: a brief, a sprint, a hard review. The agent builds and measures. I choose, every round.

One rule holds across all of it. No invented numbers. A missing figure stays a visible gap, not a guess.

### Skills for Claude and other agents

| Repo | What it does |
| --- | --- |
| [harness-atelier](https://github.com/blisse-code/harness-atelier) | Builds the working setup around the AI for a designer or design team: instructions, workflow skills, a reviewer agent, checks and a status dashboard. |
| [leadership-career-skills](https://github.com/blisse-code/leadership-career-skills) | Six skills for design leaders looking for work: resumes, case studies, stories, cover letters and portfolios. None of them invents a metric. |

| [presentation-design-skill](https://github.com/blisse-code/presentation-design-skill) | Editorial slide layouts that avoid the centred text and card grids of most AI decks. |
| [awesome-linkedin-cover-design-skill](https://github.com/blisse-code/awesome-linkedin-cover-design-skill) | Designs a LinkedIn cover with you, then checks it on desktop, mobile and the side panel. |

### Tools and research

| Repo | What it does |
| --- | --- |
| [versec](https://github.com/blisse-code/versec) | A local toolkit that tests open AI models against nine sets of tasks drawn from theories of consciousness. It collects evidence. It does not detect consciousness. |
| [ressynth-ai](https://github.com/blisse-code/ressynth-ai) | A team of AI agents that turns usability test recordings into an insight report. |
| [Klik](https://github.com/blisse-code/Klik) | An AI camera for the web. When every model fails, a filter in the browser takes over, so the camera never goes dark. |

### Live, with the code kept private

- [GeoForecast](https://geoforecast.vercel.app): a free, live world situation report beside one calm map. Every event links to its source.
- [Hundred Steps](https://100steps.vercel.app): finds a table within a short walk, by occasion, in 67 cities across 22 countries.
